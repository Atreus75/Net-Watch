# Net-Watch

A lightweight Host-Based Network Monitor written in C for Windows that correlates network activity with the processes responsible for each connection. Net-Watch focuses on behavioral detection instead of static signatures, making it useful for spotting suspicious network activity generated by legitimate tools or malware.

---

## Features

* Process-aware network monitoring
* Detection of suspicious executables making network connections (e.g. LOLBins)
* C2 beaconing detection
* Network scanning detection
* Real-time monitoring using Event Tracing for Windows (ETW)

---

## How It Works

Net-Watch subscribes to Windows ETW network events and keeps track of network activity in real time. By correlating connections from different processes, it can identify behavioral patterns such as beaconing or scanning instead of relying solely on process names or signatures.

## Installation

### Download the project

```bash
git clone https://github.com/Atreus75/Net-Watch.git
cd Net-Watch
```

### Download dependencies

```bash
wget https://raw.githubusercontent.com/DaveGamble/cJSON/master/cJSON.c
wget https://raw.githubusercontent.com/DaveGamble/cJSON/master/cJSON.h
```

### Compile

#### GCC (MinGW)

```bash
gcc -O2 netwatch.c cJSON.c -o netwatch -ladvapi32 -ltdh -lws2_32
```

#### MSVC

```bat
cl netwatch.c cJSON.c /Fe:netwatch.exe /link advapi32.lib tdh.lib ws2_32.lib
```

### Run

```powershell
.\netwatch.exe
```

## Project Goals

The objective of Net-Watch is to explore host-based behavioral detection techniques while keeping the codebase small, readable, and easy to extend. The project serves both as a learning platform and as a foundation for experimenting with new detection heuristics.
